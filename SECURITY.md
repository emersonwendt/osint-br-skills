# Comunicação privada de problemas

Use este canal — e **não** uma *issue* pública — para:

- dado pessoal, caso real ou informação sensível publicados por engano no repositório;
- conteúdo que possa facilitar dano a pessoas;
- falha em script que possa expor dados de quem o executa.

Como comunicar: use o recurso **Report a vulnerability** (aba *Security* do repositório no GitHub), que abre um canal privado com o mantenedor. Descreva o arquivo, o trecho e o risco. Não reproduza o dado sensível na mensagem além do necessário para localizá-lo.

O mantenedor confirmará o recebimento e removerá ou corrigirá o conteúdo, inclusive do histórico do repositório quando necessário.
